# CORE-004 — Implement Half Adder and Full Adder Circuits

## Description

Build single-bit Half Adder (Sum, Carry) and Full Adder (Sum, CarryOut) using destination-based logic gates.

## Acceptance Criteria

1. HalfAdder calculates Sum = A XOR B, Carry = A AND B without object allocation.
2. FullAdder calculates Sum and CarryOut for A, B, CarryIn.
3. Complete unit test suite verifying truth tables for all input combinations.
