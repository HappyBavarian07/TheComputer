# CORE-002 — Implement Byte, Word, and Address Data Primitives

## Description

Implement Byte (8-bit), Word (32-bit), and Address (16-bit) types extending FixedWidthBits.

## Acceptance Criteria

1. Byte constrained to 8 bits.
2. Word constrained to 32 bits.
3. Address constrained to 16 bits.
4. Conversion utilities to long/int and String operate accurately.
