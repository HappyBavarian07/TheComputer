# ISA-002 — Migrate to Native 64-Bit Architecture & Extended ISA

## Description

Full architectural migration to native 64-bit system: 64-bit data words and registers, 64-bit fixed instruction format (8 bytes, PC += 8), 3-operand ALU operations (Rd = Rs1 OP Rs2), direct 32-bit embedded immediates, 8-bit opcode space (256 opcodes), 64-bit address space, expanded RAM capacity, hardware MUL/DIV, subroutines (CALL/RET), and sub-word memory access (LOADB, LOADH, LOADW, LOAD).

## Acceptance Criteria

1. Word and Address expanded to 64-bit FixedWidthBits with deep bit-ownership invariants.
2. WordAdderSubtractor, WordMultiplier, and WordDivider execute 64-bit arithmetic with zero allocations.
3. 64-bit Instruction format [Opcode 8b][Flags/Cond 4b][Rd 6b][Rs1 6b][Rs2 6b][Imm32 32b] decoded by InstructionDecoder.
4. CPU fetch-decode-execute advances PC by 8 and executes 3-operand operations and 64-bit register reads/writes.
5. Sub-word memory access (LOADB/STOREB, LOADH/STOREH, LOADW/STOREW, LOAD/STORE 64-bit) implemented with little-endian encoding.
6. Assembler lexer/parser/resolver/encoder updated for 3-operand syntax (e.g., 'add r3, r1, r2'), 32-bit direct immediates, and 64-bit binary emission.
7. Test suite passes completely across all 64-bit core arithmetic, CPU execution, and assembler suites.

## Blueprint

### Goal

Transform TheComputer into a native 64-bit architecture with 64-bit data registers, 64-bit fixed instructions, 3-operand instructions, 32-bit immediates, 256 opcode slots, 64-bit address space, and expanded memory capacity.

### In Scope

- Data & Registers: Expand Word and Address to 64 bits (long backing); 32 GPRs of 64 bits (R0-R31); 64-bit PC (step +8), SP, and FLAGS.
- Arithmetic circuits: 64-stage WordAdderSubtractor, 64-bit WordMultiplier, and 64-bit WordDivider in core.arithmetic with zero allocation.
- Instruction Encoding (64 bits): [Opcode 8b][Cond 4b][Rd 6b][Rs1 6b][Rs2 6b][Imm32/Offset 32b][Reserved 2b].
- 3-Operand Format: Math ops support Rd = Rs1 OP Rs2 (non-destructive) alongside immediate forms (ADDI, SUBI).
- ISA Extensions: MUL, DIV, MOD, CMP, CMPI, CALL, RET, JMP, conditional branches (JZ, JNZ, JG, JL, JGE, JLE), PUSH, POP, HALT.
- Memory Sizing & Slicing: Sized RAM capacity (e.g. 1 MiB+), 8-byte word transfers, sub-word instructions: LOADB/STOREB (8b), LOADH/STOREH (16b), LOADW/STOREW (32b), LOAD/STORE (64b).
- Assembler pipeline: Parser grammar for 3-operand instructions and 32-bit immediates; 8-byte machine word encoding.

### Out of Scope

- Floating-point unit (FPU / IEEE-754) — separate phase.
- SIMD / Vector extensions — separate phase.
- Paging MMU (MEM-002) — builds on top of 64-bit memory layout.

### Topology

core.word.Word (64b) + core.arithmetic (64b Adder, Multiplier, Divider) -> cpu.registers (64b) + cpu.alu (64b 3-operand) -> isa (64b InstructionDecoder, 8b Opcode) -> cpu.Cpu (Fetch 8 bytes, execute) -> memory.ram.Ram (64b bus) -> assembler (3-operand 64b encoder).

### Steps

- 1. Update Architecture constants: WORD_BITS=64, ADDRESS_BITS=64, INSTRUCTION_BYTES=8, MEMORY_SIZE_BYTES expansion.
- 2. Expand Word and Address to 64 bits, update WordAdderSubtractor to 64 FullAdders, implement 64-bit WordMultiplier and WordDivider.
- 3. Upgrade RegisterFile and SpecialRegisters to 64-bit Words/Addresses.
- 4. Redesign 64-bit Instruction record, 8-bit OpCode enum, and InstructionDecoder for 3-operand format and 32-bit immediates.
- 5. Update Cpu execute engine: PC increment (+8), 3-operand ALU dispatch, CALL/RET, sub-word load/stores.
- 6. Update Memory (Ram/SystemBus) for 64-bit word read/write and sub-word masks.
- 7. Update Assembler (Lexer, Parser, Resolver, Encoder) for 3-operand grammar and 64-bit binary emission.
- 8. Update test suites and verify complete 64-bit end-to-end execution.

### Hazards

- Bit ownership: Ensure pre-allocated 64-bit arrays in Word/Address perform deep copies without aliasing.
- Zero allocation: Pre-allocate 64-bit scratch buffers in ALU, Multiplier, and Divider.
- Alignment: Instructions must align to 8-byte boundaries (PC % 8 == 0).
- Little-endian byte slicing: Correct byte ordering across 1/2/4/8 byte memory operations.
