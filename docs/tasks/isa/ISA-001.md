# ISA-001 — Define Instruction Set Architecture & Decoder

## Description

Specify instruction format, opcodes (MOV, LOAD, STORE, ADD, SUB, AND, OR, JMP, JZ, PUSH, POP, HALT), and instruction decoder.

## Acceptance Criteria

1. Complete Opcode enum and bit layout specification.
2. InstructionDecoder converts raw Word into decoded Instruction record.
3. Verification test suite for encoding and decoding all instructions.
