# CPU-003 — Implement CPU Fetch-Decode-Execute Cycle

## Description

Implement CPU main loop driving Fetch (from PC), Decode, Execute via ALU/Memory, and Writeback.

## Acceptance Criteria

1. Single-step execution executes one instruction and advances PC.
2. Execute loop runs until HALT instruction or interrupt.
3. Test execution of hand-encoded machine code programs.

## Notes

Core CPU engine.
