# CPU-001 — Implement Arithmetic Logic Unit (ALU)

## Description

Construct 32-bit ALU supporting ADD, SUB, AND, OR, XOR, NOT, Shift Left, Shift Right, and flag generation (Z, N, C, V).

## Acceptance Criteria

1. ALU accepts two input Words, control op, and writes to output Word.
2. Sets Z (Zero), N (Negative), C (Carry), V (Overflow) flags accurately.
3. Execution is entirely zero-allocation.
