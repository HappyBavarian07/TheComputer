# CPU-004 — Implement Dynamic Stack Limits & Boundary Guard

## Description

Implement dynamic STACK_BASE and STACK_LIMIT derived from Architecture.MEMORY_SIZE_BYTES and enforce StackOverflowException on stack boundary breaches during PUSH.

## Acceptance Criteria

1. Dynamic calculation of STACK_BASE and STACK_LIMIT using MEMORY_SIZE_BYTES.
2. PUSH operation checks SP against STACK_LIMIT and throws StackOverflowException if breached.
3. Unit tests verifying stack boundary traps.

## Notes

Stack memory protection.
