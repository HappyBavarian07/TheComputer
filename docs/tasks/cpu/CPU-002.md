# CPU-002 — Implement Register File and Special Registers

## Description

Implement 16 general-purpose 32-bit registers (R0-R15) and special registers (PC, SP, IR, FLAGS).

## Acceptance Criteria

1. RegisterFile allows indexed read/write of R0-R15.
2. Dedicated accessors for PC (16-bit address), SP (16-bit address), IR (Word), and FLAGS.
3. Reset method clears register state.

## Notes

Foundation for CPU execution state.
