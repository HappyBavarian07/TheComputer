# DIS-001 — Implement Disassembler (Machine → Assembly)

## Description

Convert machine code back to readable assembly for debugging.

## Acceptance Criteria

1. Disassemble machine code produced by assembler.
2. Preserve labels when possible.
3. Round-trip: assemble → disassemble → assemble reproduces identical bytes for every ISA instruction.

## Notes

Next ticket. Gates DBG-001 (the debugger's readable-assembly view is disassembly) and backs the GUI's Live Disassembly panel, which currently decodes ad-hoc.

## Blueprint

### Goal

A disassembler that decodes 32-bit machine words back into canonical assembly (mnemonic + operands) — the inverse of the assembler's encoder — driven by the same ISA opcode/operand-format tables so encode and decode can never drift.

### In Scope

- Decode one machine word into a structured instruction (opcode, operands with roles, addressing mode).
- Render a decoded instruction to canonical assembly text matching the assembler's own syntax.
- Disassemble a buffer/range into address-annotated (address, word, text) listing rows.
- Reuse ISA-001's opcode + operand-format definitions as the single source of truth for both directions.
- Deterministic, non-throwing handling of unknown/illegal encodings (emit a data directive / .word, never crash).

### Out of Scope

- Full symbol/label reconstruction (best-effort only; real symbolization needs a symbol table / debug info — future).
- Control-flow or source-level reconstruction.
- GUI and debugger wiring (they consume this module).
- Decoding privileged/interrupt instructions from ADV-001 (not yet defined).

### Topology

isa (opcode & operand-format tables) -> assembly.disassembler -> consumed by debugger + gui. One-way deps; the disassembler reads ONLY ISA definitions and raw words, never live CPU/memory runtime state. It is the mirror image of the assembler encoder and should share its ISA table.

### Steps

- Confirm/expose an ISA-001 opcode+operand-format table usable in both directions (encode and decode).
- Define decode(word) -> DecodedInstruction (opcode, ordered operands with roles/widths).
- Define render(DecodedInstruction) -> assembly string in the assembler's canonical syntax.
- Add range disassembly producing (address, word, text) rows for listings/the GUI panel.
- Handle illegal/unknown opcodes deterministically as a data directive; no exceptions on arbitrary bytes.
- Round-trip tests over every ISA instruction: text -> encode -> bytes -> disassemble -> encode again == identical bytes.

### Hazards

- Encode/decode drift: the killer risk — the disassembler MUST share ISA-001's opcode table, not hardcode its own.
- Immediate sign-extension and operand bit-widths must match the encoder exactly.
- Endianness / word order must match the assembler and memory layout.
- Unknown opcodes must degrade gracefully — the debugger will feed it arbitrary memory bytes, not just valid programs.
