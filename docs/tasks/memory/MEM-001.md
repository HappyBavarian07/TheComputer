# MEM-001 — Implement 64 KiB Memory System

## Description

Implement 64 KiB byte-addressable RAM with 16-bit Address lookup, Word read/write (little-endian), and bounds checking.

## Acceptance Criteria

1. ReadByte / WriteByte at 16-bit Address.
2. ReadWord / WriteWord handles little-endian 4-byte encoding.
3. Out-of-bounds access throws explicit exception.
