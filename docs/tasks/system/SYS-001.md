# SYS-001 — Implement Motherboard & System Interconnect Host

## Description

Build Motherboard host assembling CPU, SystemBus, RamBusDevice, and RomBusDevice, and refactor BusDevice/AddressDecoder for relative address offset translation and reset lifecycle.

## Acceptance Criteria

1. AddressDecoder & BusDevice translate system addresses to device-relative offsets (systemAddress - startAddress).
2. BusDevice defines default reset() method, and SystemBus.reset() resets signal lines and all attached devices.
3. Ram supports sized capacity constructor (Ram(capacityBytes)).
4. Motherboard instantiates SystemBus, CPU, and handles system lifecycle (powerOn, reset, stepSystem, runSystem).
5. Complete unit test coverage.
