# GPU-001 — Implement Virtual GPU & Memory-Mapped Framebuffer Display

## Description

Build high-performance virtual GPU bus device with memory-mapped VRAM framebuffer (e.g., 320x240 / 640x480 ARGB), hardware color palettes, scanline sync, and real-time host GPU texture blitting.

## Acceptance Criteria

1. VideoBusDevice exposes VRAM range with byte and 64-bit word writes.
2. Host rendering surface renders VRAM at 60 FPS via host GPU hardware acceleration.
3. Sample graphics demo (e.g. bouncing square / rainbow test pattern) runs in 64-bit assembly.
